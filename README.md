# Notepad — текстовый редактор на C#

Учебный проект, разработанный в рамках курсовой работы на втором курсе в 2025 году.

**Notepad** — настольное приложение для Windows, предназначенное для работы с текстовыми файлами, редактирования текста, анализа его содержимого и преобразования кодировок.

## Технологии

- **C#** — основной язык программирования.
- **.NET Framework** — платформа разработки.
- **Windows Forms (WinForms)** — создание графического интерфейса.
- **System.IO** — работа с файловой системой.
- **Visual Studio** — среда разработки.

## Функциональные возможности

- Создание и редактирование текстовых документов.
- Открытие и сохранение текстовых файлов.
- Перекодировка текста — преобразование файлов между различными кодировками.
- Подсчёт количества слов в тексте.
- Анализ частоты появления символов без учёта регистра.
- Графический интерфейс с меню и диалоговыми окнами.
- Проверка пользовательского ввода и обработка ошибок.

## Структура проекта

- `Блокнотик.sln` — файл решения Visual Studio.
- `Блокнотик/Блокнотик.csproj` — файл проекта C#.
- `Блокнотик/Form1.cs` — основная логика приложения.
- `Блокнотик/Form1.Designer.cs` — элементы графического интерфейса.
- `Блокнотик/Program.cs` — точка входа в приложение.
- `Блокнотик/Resources/` — ресурсы приложения.
- `Блокнотик/Properties/` — настройки и свойства проекта.

## Запуск приложения

1. Склонировать репозиторий или скачать его в формате ZIP.
2. Открыть файл `Блокнотик.sln` в Microsoft Visual Studio.
3. Установить необходимые компоненты .NET Framework, если они отсутствуют.
4. Собрать проект и запустить приложение клавишей `F5`.
